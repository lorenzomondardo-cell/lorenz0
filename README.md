<h2>📋 Sobre o Jogo</h2>

<p>
  O <b>Senha Secreta Pro</b> é um jogo interativo onde o objetivo do jogador é descobrir um código numérico gerado aleatoriamente pelo sistema no menor tempo e com o menor número de tentativas possível.
</p>

<h2>✨ Funcionalidades</h2>

<ul>
  <li><b>3 Níveis de Dificuldade:</b> Fácil (3 dígitos), Médio (4 dígitos) e Difícil (5 dígitos).</li>
  <li><b>Validação de Palpites:</b> Não permite entradas inválidas ou números repetidos.</li>
  <li><b>Histórico de Tentativas:</b> Acompanhe seus palpites anteriores para ajustar sua estratégia.</li>
  <li><b>Sistema de Pontuação e Tempo:</b> Pontuação calculada com base na rapidez e precisão.</li>
  <li><b>Recorde Local:</b> Armazena a sua melhor pontuação diretamente no navegador (<code>localStorage</code>).</li>
</ul>

<h2>🎮 Como Jogar</h2>

<ol>
  <li>Escolha o nível de dificuldade desejado.</li>
  <li>Clique no botão <b>Novo Jogo</b>.</li>
  <li>Digite seu palpite no campo numérico e clique em <b>Enviar</b>.</li>
  <li>
    Analise os resultados:
    <ul>
      <li><b>🎯 Exatos:</b> Quantidade de números corretos na posição certa.</li>
      <li><b>🟡 Fora de Posição:</b> Quantidade de números corretos, mas na posição errada.</li>
    </ul>
  </li>
  <li>Continue tentando até acertar a senha antes que suas tentativas se esgotem!</li>
</ol>
